# 自控协议 · CTDP / RSIP 试水版

把《自制力问题的两代自控技术：链式时延协议（CTDP）与递归稳态迭代协议（RSIP）》中的核心机制，做成一个移动端优先、可离线安装的静态网站。

在线试水：<https://kankna.github.io/self-control-protocol/>

## 功能

- 神圣锚点：将启动动作固定为具体、显眼、可重复的信号。
- 主任务链：完成一次专注增加一个节点；偏离时必须选择清链或永久允许。
- 15 分钟预约：把启动阻力向后平移，并对到期失约作判例。
- 5 分钟侦查：低负担进入任务环境，不计主链，可延长为主链。
- 国策树：每天最多点亮一条，崩塌时堆栈式回滚整棵子树。
- 水密隔舱：为不可抗力设置标准冻结与到期清点流程。
- 本地记录、28 天图谱、JSON 导入导出和 PWA 离线支持。

## 本地运行

```powershell
python -m http.server 8788
```

然后访问 `http://127.0.0.1:8788/`。

## 部署

项目是纯静态站点，可直接部署到 GitHub Pages。站点根目录为当前目录，`.nojekyll` 已开启。
